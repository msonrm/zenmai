# PC-98 の曲（PMD）

起動画面の曲は **PMD**（Professional Music Driver・梶原正裕さん = KAJA 作）が鳴らす。本体（`pc98_music.c`）は
常駐の PMD に `.M` を渡して頼むだけ。

| ファイル | 何か |
|---|---|
| `CANON.MML` | 曲の MML（★`gen_canon_mml.py` が作る。手で直さない）。音は `gen_canon.py`（謎カノンの書き起こし） |
| `CANON.M` | `CANON.MML` を MC.EXE で変えたもの（★`node mc98.js pc98-music/CANON.MML`）。配る |
| `PMD86.COM` | 常駐ドライバ（86 ボード = YM2608 の機種）。配る |
| `PMD.COM` | 常駐ドライバ（26K = YM2203 の機種）。配る |
| `.mc/` | 道具の置き場（追跡しない）。`sh build-mc.sh` が MC.EXE と、上の 2 つの元を建てる |

## 出どころとライセンス

KAJA さんは 2019-12-25 に PMD / MC / PMP の全ソースを公開し、「ソースについての著作権は放棄しませんが、
**ご自由に使って頂いて構いません**。むしろ…再利用するアイデアがあるようでしたら、ぜひ利用してやってください」と
明記した（https://github.com/d2lmirrors/pmd のミラー・commit `c620dc95c5e47970e7839cb5f0b7b9ab742d4f46`）。
`PMD86.COM` / `PMD.COM` / `MC.EXE` はそこから **Zenmai が自分でビルドしたもの**（`build-mc.sh`・アセンブラは UASM）。
★1997 年配布のバイナリは「無断の改変・営利使用を禁ず」の別ライセンスなので使わない。
QuuBee（`tools/pmd_build/`）が同じソースから建てた `PMD86.COM` と **byte 一致**する（下の SHA-256）。

```
PMD86.COM  704a40c518032b5758d76db79772dba9c79e2c2d05eda4a22fd340a46d7a43f0
PMD.COM    1dab25533ee8ec0f7b613d15085c2f7245540ee379a455648e28f698673ea666
```

## 曲の作りと確かめ方

- ★編曲（2026-09-30・msonrm の「ZUN サウンド風にしてよい・楽しんで」）: A/B = FM 2 声（先の声・後の声を別の音色に）・
  G/H = SSG が同じ旋律を「ぽろん」と重ねる・K/R = SSG ドラム（26K でも鳴る。86 なら PMD がリズム音源も同時に鳴らす）。
  テンポは四分音符 = 132。ドラムは 1 小節を休んで入り、4 小節ごとにフィル（タム）、最後にクラッシュ。
- ★`.M` の枠は PMD の既定で 16KB。CANON.M は約 2KB
- ★MML の改行は **CRLF**（LF だけの行があると MC が行を数え損ねて `@` の音色定義を「理解不能な文字」と言う）。
  音色を MML の中に書くには**音色ファイル（.FF）が先に要る**（無いと `@` が通らない）—— `mc98.js` が空の .FF を置いて渡す
- ★1 音符は 255 クロックまで（超えると「指定された音長が長すぎます」）—— `&` でつないで割る
- ★鳴らす側の罠は `pc98_music.h`（DOS/4GW の下から INT 60h を呼ぶ・DS は使えない）
- 音を聞かずに確かめる: QuuBee の headless で PMD86 を常駐させ、`Machine.captureAudio()` で録って
  音の高さ（FFT）とピークを見る（2026-09-30: o4 の C = 261 Hz。音量はドラム以外を上げた（msonrm・2026-09-30）: FM = V127・搬送波 TL 0・SSG = v13 で、ピーク 28.5k / 32.7k（割れない））
